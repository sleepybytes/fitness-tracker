# Fitness Tracker

A personal iPhone app for following a lean-bulk diet plan, tracking supplements and workouts, and
seeing what was missed. Built with Expo (React Native). All data stays on the phone.

## Features

- **Diet**: the trainer's meal timeline (7 AM to 10 PM). Tick whole meals or single items, and track water.
- **Supplements**: protein, multivitamin and omega-3, logged with the dose actually taken.
- **Exercise**:
  - muscle groups, free-text exercises (e.g. "Hammer curl 3x12")
  - duration, intensity, notes
  - rest days
  - body weight
- **Reminders**: a local notification at each meal and supplement time, a 7 PM "log your workout"
  nudge, and a 10:30 PM check-in. A reminder is skipped once that item is logged.
- **Insights**:
  - adherence, streaks, and a daily completion chart
  - most-missed meals and foods
  - muscle-group frequency and "due for a session"
  - weight trend
- **Past days are view-only.** Only today can be edited.

## Getting started

```bash
npm install
npx expo start        # scan the QR code with Expo Go, or press i for the iOS simulator
```

The project uses **Expo SDK 57** so it runs in the App Store version of Expo Go.

## Checks

```bash
npm test              # Jest: insights, reminders, workout logic, screens
npx tsc --noEmit      # typecheck
npx expo lint         # lint
```

## Install on an iPhone (standalone, no Mac needed to run)

```bash
cp .env.example .env.local   # once: set APPLE_TEAM_ID, APP_BUNDLE_ID (and optionally your name)
npm run ios:device           # Release build, signed with a free Apple ID, installed on the connected iPhone
```

With a free Apple ID the app expires after 7 days, so re-run the command to refresh it. See
[INSTALL-IPHONE.md](INSTALL-IPHONE.md) for the one-time setup and the paid ($99/yr) EAS option.

## Project layout

```
app/                     screens (Expo Router): Today, Insights, Settings
src/data/plan.ts         the diet plan, supplements, muscle groups (single source of truth)
src/data/nutrition.ts    rough kcal/protein per item for the "missed" estimate
src/store/useTracker.ts  Zustand store, persisted with AsyncStorage
src/lib/                 insights, workout insights, notifications, dates
src/components/          UI: meal cards, workout logger, charts
plugins/                 config plugins needed for the iPhone build (see below)
scripts/install-iphone.sh
__tests__/
```

To change the diet plan, edit `src/data/plan.ts`.

## Notes

- `plugins/withSceneLifecycle.js`: apps built with Xcode 27 (the iOS 27 SDK) must use UIKit's scene
  life cycle, and SDK 57's native template doesn't. Remove this plugin after upgrading to SDK 58.
- `plugins/withoutPushEntitlement.js`: the app only uses local notifications, so it drops the push
  entitlement. That is what lets a free Apple ID sign the app.
- `ios/` is generated by `npx expo prebuild` and git-ignored. Don't edit it by hand.
